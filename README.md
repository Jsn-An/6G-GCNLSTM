# GNN-based Congestion Prediction and Task Offloading Optimization

这是一个用于 5G/6G 边缘网络拥塞预测与任务卸载优化的项目骨架。当前阶段仅建立简洁完整的目录结构，后续再逐步补充数据处理、建模、训练和优化代码。

## 目录说明

- `datasets/`: 原始数据与数据生成脚本
- `data/raw/`: 原始输入数据副本
- `data/interim/`: 中间处理结果
- `data/processed/`: 可直接用于建模的数据
- `configs/`: 配置文件
- `src/`: 核心 Python 代码
- `scripts/`: 可执行脚本
- `notebooks/`: 实验与可视化笔记本
- `reports/`: 图表和表格输出
- `results/`: 模型、指标和预测结果
- `tests/`: 测试代码
- `docs/`: 说明文档
